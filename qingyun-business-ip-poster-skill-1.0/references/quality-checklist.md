# 海报质量检查清单

## A. 人物

- [ ] 与上传照片是同一个人
- [ ] 脸型、五官、发际线、年龄感未漂移
- [ ] 没有无依据添加眼镜、胡须、首饰
- [ ] 皮肤真实，不是塑料磨皮
- [ ] 手指、手臂、麦克风、领带、衣领正常

## B. 文案

- [ ] 姓名准确
- [ ] 主标题无错字、漏字、多字
- [ ] 身份、机构、数字、奖项与用户输入一致
- [ ] 未生成用户没有提供的品牌、峰会或客户
- [ ] 资历最多 5 条，信息不过载

## C. 传播

- [ ] 手机缩略图能一眼读出主标题
- [ ] 主标题不超过 4 行
- [ ] 主标题是第一视觉
- [ ] 姓名与身份容易找到
- [ ] 没有重要文字贴边或落入裁切区

## D. 审美

- [ ] 每张只用一种强调色
- [ ] 每张只强调一个关键词、数字或结论
- [ ] 有足够留白
- [ ] 不像廉价课程促销海报
- [ ] 有国际商业杂志或思想领袖气质

## E. 批量差异

- [ ] 人物位置有左、中、右变化
- [ ] 至少包含三种景别
- [ ] 至少包含三种姿态或场景
- [ ] 标题结构不是全部一样
- [ ] 不是简单换色或换背景

## 交付门槛

任一版本出现以下问题，不应直接交付：

- 人脸不像本人
- 标题关键字错误
- 姓名错误
- 手指明显畸形
- 用户未提供的 Logo 或大会名
- 画面拥挤到无法阅读
- 与其他版本高度重复
