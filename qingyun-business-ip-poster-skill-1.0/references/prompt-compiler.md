# 图像生成指令编译模板

## 主模板

将方括号内容替换为用户信息，并为每个版本单独填写。

```text
创建一张专为商业领袖/行业专家定制的高级个人 IP 宣传海报，竖版 3:4，适合视频号、小红书、抖音发布。

人物身份：上传的 [3/5] 张照片均为同一个人——[姓名]。以最清晰正脸照片锁定五官身份，以半身/侧面/演讲照片辅助体型、姿态和职业状态。必须保持脸型、眼距、眉眼、鼻形、嘴形、下颌线、发际线、肤色、年龄感及显著面部特征，不能换成相似的另一个人，不能过度年轻化或网红化。

本版视觉方向：[版本名称]
人物镜头：[超近景/近景/半身/3/4身]
人物位置：[左/中/右]
人物动作：[正面直视/侧面思考/双手交叠/演讲手势/手持麦克风]
服装：[深灰双排扣西装、白衬衫、深色领带等]
背景：[峰会暗场/高级办公室/石墨灰棚拍/暖象牙白编辑空间/抽象建筑]
灯光：[克制的电影级人物光，真实皮肤质感，柔和轮廓光]

主标题必须准确显示：
“[主标题]”

姓名：
“[姓名]”

身份/职位：
“[身份]”

核心背书：
1. [背书1]
2. [背书2]
3. [背书3]
4. [背书4]
5. [背书5]

视觉强调：只使用一种强调色 [荧光绿/信号黄/香槟金/墨绿]，只强调 “[关键词或数字]”，其余为深黑、石墨灰、暖白。

版式：国际商业杂志、思想领袖封面、信息层级清晰。主标题是第一视觉，姓名第二，背书第三。大留白、精确对齐、克制线条、少量低对比背景字。标题缩小到手机缩略图仍清晰可读。

禁止：廉价互联网运营风、蓝紫科技光、芯片线路、满屏荧光、玻璃拟态堆叠、无关 Logo、虚构峰会、英文水印、错别字、人物身份漂移、畸形手指、麦克风穿模、过度磨皮。
```

## 演讲现场版补充

```text
人物处于真实大会演讲状态，手持麦克风或演示器，动作自然，有现场交流感；背景观众与舞台保持低对比虚化。不要出现用户未提供的大会名称或麦标文字。
```

## 超近景特写版补充

```text
面部占画面约一半，保留真实皮肤纹理与本人五官比例。主标题位于顶部，不覆盖眼睛、鼻子和嘴。背景仅使用低对比超大轮廓字或细线。
```

## 暖白双栏版补充

```text
画面左侧为暖象牙白编辑空间，人物位于中下部；右侧为深黑信息栏，使用统一线性图标和最多五条资历。整体像高端商业杂志人物专访，不像招聘海报。
```

## 黑金权威版补充

```text
使用黑色、暖白与香槟金，避免土豪金和金属3D字。人物正面居中，背景为克制的竖向建筑线条与柔和金色光晕，体现权威和纪念性。
```
