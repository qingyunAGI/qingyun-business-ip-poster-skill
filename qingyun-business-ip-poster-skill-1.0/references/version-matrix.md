# 版本矩阵与批量差异控制

## 版本标记字段

为每个版本建立内部标签：

- `scene`：演讲 / 办公室 / 访谈 / 会议桌 / 极简棚拍 / 建筑空间
- `shot`：超近景 / 近景 / 半身 / 3/4 身 / 全身
- `pose`：正面 / 侧面 / 思考 / 手势 / 双手交叠 / 站姿
- `subject_position`：左 / 中 / 右 / 跨栏
- `layout`：上标题 / 左标题 / 右侧栏 / 双栏 / 对称 / 大留白
- `palette`：黑绿 / 黑黄 / 黑金 / 暖白墨绿 / 石墨灰
- `emphasis`：关键词 / 数字 / 问号 / 标签 / 活动身份

## 相似度检查

任意两张版本若同时满足以下 4 项中的 3 项，应判定过于相似并重做：

- 人物都在同一侧
- 镜头景别相同
- 标题断行相同
- 背景都是同一类黑色办公空间

## 系列一致性

批量方案仍需保持：

- 同一人物身份
- 同一标题主题
- 同一专业定位
- 相同事实文案
- 统一的高级商务审美

差异来自视觉叙事，不来自虚构不同身份。
